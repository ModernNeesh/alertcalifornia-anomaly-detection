# Quality of Service Anomaly Detection in Wildfire Monitoring Networks
*Understanding how Vision Transformers can act as effective models for anomaly detection in outdoor cameras.*

## Structure of Repository

This repository contains the code used to obtain the results in our paper, *Quality of Service Anomaly Detection in Wildfire Monitoring Networks*, which can be found here (link pending). The folders are strucutured as follows:

* `camera_data`: contains the following:
  * The `dataframes` folder contains the training, validation, and test data used during training
  * The `images` folder is, by default, where images are downlaoded to.
  * All raw data pulled from LabelStudio is also present here. CSV files contain only labeled data, while JSON files contain both labeled and unlabeled data.
* `embedding_data` stores the embeddings generated by the model during inference.
* `outputs` contains the predicitons and throughput results from inference tests
* `src` contains the library code used throughout the paper

Meanwhile, some scripts are also available to run:

* `model_test_runs_triplet.ipynb`, `model_test_runs_deepsad.ipynb`, and `model_test_runs_hierarchical.ipynb` contain code that reproduces the baseline models we obtained from each of the following objective functions: triplet margin loss, DeepSAD, and Hierarchical SAD, respectively. Explanations of these functions can be found in our report linked above.
* `model_test_runs_finalized.ipynb` contains code that reproduces the finalized model we obtained and demonstrates its generalizability to the training set.
* `run_inference.py` uses a pre-trained model to run inference on a specified set of data. By default, this is the combined training, validation, and testing datasets.
* `inference_analysis.ipynb` analyzes the results obtained after running `run_inference.py`.

## Instructions

### 1. Create virtual environment and install dependencies
  Make sure you have:

- Python 3.12 installed  
- `pip` installed

Check versions:

```bash
python --version
pip --version
```

#### Windows
```powershell
python -m venv venv
venv\Scripts\activate.bat
pip install -r requirements.txt
```

#### macOS / Linux
```bash
python3 -m venv venv
source venv/bin/activate
pip3 install -r requirements.txt
```

### 2. Ensure necessary files are included
  In order to train a model and/or perform inference, labeled data from LabelStudio is necessary and must be in the form of a CSV file. This data is not publicly avaliable. The following instructions pertain to those who have access to the file containing the data.
  By default, the program checks for a file named `coronado_hills_data.csv` in the `camera_data` directory. If you wish to use a different name and/or location, please refer to the `--labels-csv-name` and `--camera-data-dir` arguments respectively. .

### 3. Run program
  If you wish to use the default settings, simply run:
  ```powershell
  python main.py
  ```
  This will download the images to the `camera_data/images/` directory, train a new model, place its weights (named `model_weights.pth`) in the `weights/` directory, and save the training, validation, and test set embeddings 
  generated by the model to the `embedding_data/` directory. If you wish to change these default settings, run the following command to view documentation for each of the arguments:

  ```powershell
  python main.py -h
  ```
